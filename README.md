# FMP Project

This is my Final Major Project (FMP) - A 2D platformer loosely inspired by metroidvanias demo

## What is it

You explore a scene while picking up powerups, defeating enemies and using movement to navigate obstacles. There are both natural hazards such as spikes (hazardscriptspike.cs) and actual patrolling enemies that will kill you if enough damage is taken from the players total as well as obstacles there is a powerup that allows the player to fire projectiles at enemies (playershooting.cs).
